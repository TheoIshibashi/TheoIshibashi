## 📌 Projetos em destaque

### 🍽️ Recipe Finder

Aplicação Full Stack para explorar receitas, com **Python, FastAPI e HTTPX** no backend e **React, TypeScript e Vite** no frontend, em repositórios separados.

- Integração assíncrona com a **TheMealDB**, sem banco de dados próprio.
- Busca por nome ou ingrediente, receita aleatória, categorias e detalhes das receitas.
- Validação e transformação de dados com **Pydantic**, tratamento de falhas da API externa e testes automatizados com **pytest**.
- Interface responsiva com estados de carregamento e mensagens de erro.

### 🎮 Gaming Hub — Good Game

Aplicação Full Stack para consultar ofertas e comparar preços de jogos entre lojas, integrando uma API externa e conversão de moedas entre **BRL e USD**.

Repositórios: `good-game-backend` e `good-game-frontend`.

### 🏋️ Persista Back — fitprojects

Contribuição em um ecossistema de gestão de academias e acompanhamento de métricas corporais, com implementação de **endpoints de medições**, validação de requisições e integração administrativa via **Filament**.

### 🤖 FlappyBird_PythonAI
